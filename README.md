# Experiment-3

### Aim

To write a Python program to demonstrate various string operations such as finding the length, converting uppercase and lowercase, accessing characters, searching, slicing, replacing, concatenating and removing extra spaces from a string.

### Algorithm

1. Start the program.
2. Initialize a string variable `s` with the value "hello python".
3. Display the original string.
4. Find and display the length of the string using `len()`.
5. Convert the string into uppercase using `upper()`.
6. Convert the string into lowercase using `lower()`.
7. Access and display the character at index 6.
8. Find the position of the word "python" using `find()`.
9. Extract a part of the string using slicing.
10. Replace the word "python" with "world" using `replace()`.
11. Display the original string again.
12. Check whether the word "python" is present using the `in` operator.
13. Perform string concatenation by joining the string with "programming".
14. Initialize another string with extra spaces.
15. Remove the extra spaces using `strip()` and display the result.
16. Stop the program.
